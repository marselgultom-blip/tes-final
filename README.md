# Iklimara — materi dan tampilan dipertahankan

Website ini memakai tujuh halaman HTML dan stylesheet bersama. Penambahan pada paket ini hanya mencakup menu hamburger yang dapat dibuka pada laptop maupun handphone (HTML/CSS tanpa JavaScript) dan baris copyright di bagian bawah setiap halaman.

## Halaman
1. `index.html` — Beranda
2. `iklim.html` — Mengenal perubahan iklim
3. `penyebab.html` — Penyebab dan jejak karbon
4. `dampak.html` — Dampak perubahan iklim
5. `mitigasi.html` — Mitigasi perubahan iklim
6. `adaptasi.html` — Adaptasi dan aksi iklim
7. `tentang.html` — Tentang dan daftar pustaka

Buka `index.html` di browser atau gunakan Live Server. Jangan pisahkan folder `css` dan `images`.


## CSS per halaman
Setiap halaman HTML menggunakan file CSS masing-masing di folder `css`: `index.css`, `iklim.css`, `penyebab.css`, `dampak.css`, `mitigasi.css`, `adaptasi.css`, dan `tentang.css`. Dengan begitu, gaya tiap halaman dapat diedit secara terpisah. Pada layar HP, menu utama berada dalam satu baris horizontal yang bisa digeser ke kanan/kiri, bukan tersusun menjadi beberapa baris. Ikon menu cepat saat scroll tetap tersedia sesuai perilaku sebelumnya.


Revisi terbaru: pada layar HP, navigasi utama disembunyikan sampai ikon garis tiga ditekan; menu terbuka vertikal dan dapat dipilih. Di bawah setiap gambar utama tersedia placeholder “Sumber gambar: [isi sumber gambar ini]” untuk diisi dengan sumber asli gambar. CSS tetap dipisah per halaman.


**Keterangan ilustrasi:** Gambar pada halaman selain halaman Mengenal Iklim diberi keterangan bahwa ilustrasi dibuat dengan bantuan AI untuk situs Iklimara. Halaman Mengenal Iklim tetap memakai placeholder sumber gambar sesuai permintaan.


Keterangan sumber gambar: gambar pada halaman Beranda, Penyebab, Dampak, Mitigasi, Adaptasi, dan Tentang menggunakan foto Unsplash dengan tautan kredit di bawah gambar. Gambar pada halaman Mengenal Perubahan Iklim tetap dipertahankan; teks sumbernya berupa template yang dapat diisi sendiri.
